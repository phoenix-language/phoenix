# Review: VM (`phx-vm`)

## Summary

The MVP VM is a **deterministic, safe-Rust stack interpreter** with width-faithful scalars, an aggregate arena, and tagged local/heap pointers. Review 07 closed **test and correctness gaps**: `PtrStore` honors the signed operand on heap stores, `ConstTag::Bytes` fails loudly instead of `Ptr(0)`, `ENTRY_NONE` is rejected at run time, integration semantics cover `ref_local` / `deref_ptr` / `byte_string`, typeck rejects **returning borrows of locals**, `phx-vm` has defense-in-depth `VmError` tests on unverified bytecode, and `VmRunCapture` exposes slot-index / `return_value` for integration tests (review 09). **Deferred:** per-frame arena reclaim, compiler `Alloc` lowering, full borrow checker, scheduler/I/O.

## Findings

1. **No `unsafe` in VM today** — **Documented (positive)**
   Implementation remains safe Rust; any future hot-path `unsafe` stays inside [`interpreter.rs`](../../source/phx-vm/src/interpreter.rs) with `// SAFETY:` comments.

2. **`run_captured` / `main_locals` test contract** — **Addressed**
   [`VmRunCapture::main_local`](../../source/phx-vm/src/interpreter.rs) and optional `return_value` support slot-index semantics in [`run_semantics.rs`](../../tests/integration/tests/run_semantics.rs). `#[doc(hidden)]` integration-test-only API documented in [`lib.rs`](../../source/phx-vm/src/lib.rs).

3. **Slice views over stack-backed arrays** — **Partially addressed (MVP rule)**
   Typeck [`ReturnEscapesLocal`](../../source/phx-diagnostics/src/type_error.rs) (E2022) rejects returning `&T` / `[T]` formed from local bindings; see [`ownership.md`](../design/features/ownership.md). VM frame-generation debug asserts deferred.

4. **`ConstTag::Bytes` → `Ptr(0)` stub** — **Addressed**
   [`load_const`](../../source/phx-vm/src/interpreter.rs) returns [`VmError::UnsupportedConst`](../../source/phx-vm/src/error.rs). Byte string literals lower to `MakeArray` in [`lower/expr.rs`](../../source/phx-compiler/src/lower/expr.rs).

5. **`Alloc` opcode without compiler lowering** — **Documented (deferred)**
   VM implements heap bump; compiler emission waits on intrinsic kernel per [`grammar-deferred.md`](../design/features/grammar-deferred.md) and finished review 06.

6. **`PtrStore` ignores signed operand** — **Addressed**
   `ptr_store` passes `signed` into heap path via `scalar_store_bytes` (mirrors `read_heap_scalar`).

7. **Call frame `pop().expect`** — **Addressed**
   `phx-vm` uses workspace `expect_used` deny; `Opcode::Call` returns [`VmError`](../../source/phx-vm/src/error.rs) via `ok_or` instead of `expect` (see [`10-rust-code-quality.md`](10-rust-code-quality.md)).

8. **Arena not freed per frame** — **Documented (deferred)**
   Process-lifetime arena documented in [`frame.rs`](../../source/phx-vm/src/frame.rs); reclaim before schedulable I/O is post-MVP.

9. **No VM tests for malformed bytecode** — **Addressed**
   [`phx-vm/src/lib.rs`](../../source/phx-vm/src/lib.rs) tests: stack underflow, invalid local, invalid call target, unsupported bytes const.

10. **Std readiness gap** — **Documented (future)**
    Scheduler, syscalls, and I/O parking remain out of MVP scope per [`mvp.md`](../design/mvp.md).

## What's working well

- **Stack convention** documented and aligned with codegen.
- **Tagged pointers** for locals vs aggregates ([`scalar.rs`](../../source/phx-bytecode/src/scalar.rs)).
- **Exhaustive opcode dispatch** for MVP PHX0.
- **Verified modules** in integration tests (`verify` before `run_captured`).

## Recommended next actions

1. Compiler lowering for `Alloc` / assignment through raw pointers when alloc intrinsics are specified.
2. Optional VM debug assert: slice base tag still refers to a live frame slot.
3. Per-frame arena reset before long-running or server-style workloads.
